# AI가 만든 연구 코드 검증 체크리스트

발표 전에 내 결과에 대해 아래를 확인합니다. "확인한 방법"을 한 줄씩 적을 수 있어야 통과입니다.

## 입력
- [ ] 모든 배열의 shape를 출력해 계약서 값과 비교했다 (1762 / 994 / 29 / 64)
- [ ] 쿼터니언 성분 순서를 **다른 표현과 교차 검증**했다 (예: 축-각 `pose_aa`와 비교)
- [ ] 관절 순서(IsaacLab ↔ MuJoCo)를 이름으로 한 개 이상 직접 확인했다
- [ ] 시간축(fps, 길이, 보간 방식)을 확인했다
- [ ] 기본각 오프셋·단위(rad/deg, m)를 확인했다

## 처리
- [ ] 이력 순서(오래된 → 최신)를 값으로 확인했다 (예: 프레임 번호를 값으로 넣은 가짜 이력)
- [ ] 불변식 테스트가 있다 (기본 자세 → 관측 q=0, 똑바로 선 자세 → 중력 (0,0,−1), action=0 → 목표=기본각)
- [ ] 코드가 실패할 때 **조용히 넘어가지 않고** 에러를 내도록 assert가 있다

## 실험
- [ ] 기준 조건(공식 샘플·공식 모드)과 내 조건을 같은 코드로 비교했다
- [ ] 결과 지표의 의미를 안다 (완주 ≠ 동작 품질)
- [ ] 무작위성·초기 조건을 고정하거나 반복했다
- [ ] 영상은 '보여주기'일 뿐, 판단은 수치로 했다
